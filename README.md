# shark.n3t
shark.n3t is an open source music database that compiles a list of files into folders sorted alphabetically. Links on PC/MAC open with any browser // Links on Android/iOS open with Opera Browser

shark.n3t runs on a single powershell command executed with a batch file. Alternative methods include a python script, VBS script and batch files.

in this repository the names list (a txt document with the names of what the powershell command creates file-names with) / the start.bat batch file (with which the powershell command is executed) / and the powershell command (a ps1 file run entirely in the same folder as the index)

shark.n3t includes a list of 56,600 mp3 titles, ranging from all genres, and can be edited to the users usage. 

TO RUN THE COMMAND :

put an image file, the ps1 command, the start batch file and the nameslist in the same folder, and execute the start batch file.

RESULT :

an alphabetically arranged database with the nameslist as folder names

note : the folders will include 3 links and an image of choice : a google image search url link, a google search url link, a youtube search url link, and the image of choice.
